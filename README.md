# EE6407 — Pattern Recognition Assignments

Python implementations for the two EE6407 assignments:

- `assignment-1` — Gaussian Naive Bayes classification.
- `assignment-2` — Fisher Linear Discriminant.

Each implementation is maintained on its own branch. To view one:

```bash
git switch assignment-1
git switch main
git switch assignment-2
```

The assignment branches contain the corresponding code, usage notes, and synthetic regression tests. Course-provided datasets and assignment PDFs are not included; provide the original files locally when running a solution.
